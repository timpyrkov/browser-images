1. 	Tab Stash por Josh Berry
[https://addons.mozilla.org/es-ES/firefox/addon/tab-stash]
[https://github.com/josh-berry/tab-stash/]
Easily save and organize batches of tabs as bookmarks. Clear your tabs, clear your mind. Only for Firefox.

2.	Tabby - Window & Tab Manager por BillK
[https://addons.mozilla.org/es-ES/firefox/addon/tabby-window-tab-manager]
[https://github.com/Bill13579/tabby]
Tabby helps you manage a lot of windows and tabs easily; it can help you open, close, move, pin, and do many other things on tabs and windows quickly. With Tabby, you can even save all you windows and tabs for later with just one click!

4.	Tab Session Manager por sienori
[https://addons.mozilla.org/es-ES/firefox/addon/tab-session-manager]
[https://github.com/sienori/Tab-Session-Manager]
Save and restore the state of windows and tabs. It also supports automatic saving and cloud sync.

5.	Count Tabs por sienori
[https://addons.mozilla.org/es-ES/firefox/addon/count-tabs]
Displays the number of open tabs in that window. I was inspired by the following great add-ons, developed as an add-on for Firefox 57 or later. Tab Counter.

6.	FoxyTab por erosman
[https://addons.mozilla.org/es-ES/firefox/addon/foxytab]
Collection of Tab Related Actions e.g. Duplicate, Close Duplicates, Close to the Left, Copy Title, Merge Windows, Save as PDF, Copy Urls Tab/All/Left/Right, Host keep/close/close other, Sort by URL/Title, Asce/Desc, Move, Reload, Reload Timer

7.	Tree Style Tab (Pestañas estilo árbol) por Piro (piro_or)
[https://addons.mozilla.org/es-ES/firefox/addon]
Muesta las pestañas en vista de árbol

8.	Simple Tab Groups por Drive4ik
[https://addons.mozilla.org/es-ES/firefox/addon/simple-tab-groups]
Create, modify, and quickly change tab groups

9.	OneTab por OneTab Team
[https://addons.mozilla.org/es-ES/firefox/addon/onetab]
[]
¿Demasiadas pestañas? Convierte tus pestañas en una lista y acelerar a Firefox ¡OneTab ya está disponible en Español!

10.	Tab Reloader (page auto refresh) por James Fray
[https://addons.mozilla.org/es-ES/firefox/addon/tab-reloader]
An easy-to-use tab reloader with custom reloading time settings for individual tabs

11.	Adaptive Tab Bar Colour por Eason
[https://addons.mozilla.org/es-ES/firefox/addon/adaptive-tab-bar-colour]
[https://github.com/easonwong-de/Adaptive-Tab-Bar-Colour]
Cambia el color de la barra de pestañas de Firefox para que coincida con el tema del sitio web.
